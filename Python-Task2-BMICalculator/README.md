# Task 2 — BMI Calculator (Advanced)

Tkinter BMI calculator with named-user records stored in SQLite, colour-coded BMI categories, history table, and trend chart.

## Run
```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```
Enter weight in kilograms and height in centimetres. BMI is a screening measure, not a diagnosis; categories shown are the standard adult categories specified in the task brief. The database is created automatically.
